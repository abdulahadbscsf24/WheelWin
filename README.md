# 🎡 WheelWin — Interactive Name Spinner

> **Spin. Pick. Win. 🏆**

WheelWin is a modern and interactive **random name spinner game** built with **HTML, CSS, and Vanilla JavaScript**.

Add names to the wheel, press the **SPIN** button, and watch the wheel rotate at high speed before gradually slowing down and stopping exactly on the selected winner.

---

## ✨ Features

- 🎡 Interactive spinning wheel
- ➕ Add names dynamically
- 🗑️ Remove names
- 🏆 Automatic winner selection
- ⚡ Fast spinning animation
- 🐌 Smooth slow-down effect
- 🎯 Wheel stops exactly on the selected winner
- ❓ Winner confirmation popup
- ✅ Remove winner after selection
- ❌ Keep winner and continue playing
- ⭐ First 3 inserted names have priority
- 🎲 Random selection after priority names
- 💾 Game data saved with LocalStorage
- 🔄 Data remains after page refresh
- 🚫 Prevents multiple spins at the same time
- 📱 Responsive design
- 💻 Works on desktop and mobile
- 🎨 Modern UI
